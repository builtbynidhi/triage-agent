## address.before_dispatch

The delivery address can be changed once per order, free of charge, while the order status is "placed". The customer must send the order ID and the complete new address.

## address.after_dispatch

After dispatch the address cannot be changed because the parcel is already with the courier. The customer may contact the courier using the tracking link, or refuse delivery and reorder.

## address.requirements

A valid new address has the recipient name, house or flat number, street, city, state, a 6-digit PIN code and a contact phone number. If any of these is missing the agent asks only for the missing parts before the change can be made.
